Entry for the [make.fun](https://make.fun/c/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21) competition **"Make the Judge Laugh in One Line"** — one funny line, 200 characters or fewer, judged head to head by an AI judge on surprise, tightness, freshness, and readability.

## The line

> My grandfather warned me never to trust a man with two first names. His name was James James.

(93 characters.)

## How it works

`main.py` (pure Python standard library, no dependencies, no network) writes the
one-liner to `/output/entry.txt`, where the competition's gate checks it
(UTF-8 text, 1–200 characters) before it goes before the judge.

```sh
python3 main.py
```
